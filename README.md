# THE ROOM — V0.7 RELEASE CANDIDATE

A lightweight, cinematic nostalgia experience for GitHub Pages.

## Release status
**Release Candidate** — the feature set is intentionally frozen. The next changes should be visual/content polish only.

## Included
- Three cinematic scenes
- In-place scene transitions
- Discoverable memories
- Completion/finale flow from the previous build
- Lightweight browser ambience
- Image preloading
- Mobile swipe/keyboard support
- Reduced-motion support
- SVG favicon
- No backend, database, API, framework or build step

## GitHub Pages
1. Create a new GitHub repository.
2. Upload **everything inside this folder**.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Branch: `main`
6. Folder: `/root`
7. Save.

## Before public launch
Test:
- Chrome desktop
- Edge desktop
- Chrome Android
- Safari/iPhone
- Mobile landscape
- First load with slow network
- Sound on/off
- Keyboard navigation
- Reduced-motion accessibility

Keep the first public version simple. Add new scenes only when the existing experience feels finished.
